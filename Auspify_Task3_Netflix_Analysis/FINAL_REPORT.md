# Auspify Task 3: Country-Wise Netflix Content Analysis

## 1. Project Overview
This project analyzes Netflix movies and TV shows by country using Python. The objective is to understand content distribution across countries and compare the production of movies and TV shows.

## 2. Objectives
- Analyze Netflix content by country.
- Identify the top 10 countries by number of titles.
- Compare movies and TV shows across leading countries.
- Clean country information and handle missing values.
- Present findings using data visualizations.

## 3. Tools and Technologies
- Python
- Pandas
- Matplotlib
- CSV datasets
- Visual data analysis

## 4. Methodology
1. Loaded the Netflix dataset.
2. Removed duplicate records.
3. Cleaned country information.
4. Split multiple country names associated with a title.
5. Counted titles by country.
6. Compared movies and TV shows.
7. Generated charts and exported the results.

## 5. Deliverables
- Cleaned Netflix dataset
- Country-wise content counts
- Country and content-type breakdown
- Top 10 countries chart
- Movies versus TV Shows chart
- Business insights summary

## 6. Conclusion
This project demonstrates how Python-based data cleaning, analysis, and visualization can help explore Netflix's geographic content distribution. The results can support further investigation into content types and country-level patterns.
