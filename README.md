# Auspify Task 3: Country-Wise Netflix Content Analysis

## Project Overview
This project analyzes Netflix movies and TV shows by country using Python, Pandas, and Matplotlib.

## Objectives
- Identify countries with the highest number of Netflix titles.
- Compare movies and TV shows across countries.
- Clean and process country-level data.
- Create visualizations and summarize business insights.

## Technologies Used
- Python
- Pandas
- Matplotlib

## How to Run
1. Install Python.
2. Install the required packages:
   `python -m pip install pandas matplotlib`
3. Place the dataset in the project folder as `Dataset.csv`.
4. Run:
   `python netflix_analysis.py`

## Outputs
The project generates cleaned data, country-level summaries, visualizations, and business insights.

## Conclusion
This project demonstrates data cleaning, exploratory data analysis, and visualization techniques for understanding Netflix content distribution by country.
